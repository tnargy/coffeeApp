# Coffee Roasting App — OpenSpec Starter

This folder contains an OpenSpec-style specification structure for the internal coffee roasting inventory, roasting, packaging, and sales tracking app.

## Structure

`openspec/specs/` is the current behavior contract. `openspec/changes/archive/` is finished work. Operator and code flowcharts live in `docs/flows.md`, not here.

Current capabilities: inventory, roasting, resting-and-packaging, sales, customers, dashboard, corrections, backup, appearance, weight-display.

## How to use

Propose a change, implement it, sync the delta into `specs/`, then archive. Do not treat an archived change as the current spec.
